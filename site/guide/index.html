安装与打开

  1. 下载 ZIP 安装包并解压。
  2. 如果旧版仍在运行，请在系统托盘里右键“轻待办”，选择“退出轻待办”。
  3. 双击“一键安装.exe”，安装完成后会创建桌面入口并打开程序。

完整程序已内置在安装文件中，无需再联网下载。安装位置为 %LOCALAPPDATA%\Programs\QingTodo。以后可以直接双击桌面入口。

添加与排序

在输入行写一件事，按 Enter 或点 ＋ 保存。时间可选。点击现有文字可修改；勾选方框完成事项。

按住左侧 ⠿ 手柄上下拖动。卡片会轻微浮起，其他事项平滑让位，绿色线表示放置位置。松手后滑入新位置，越靠前越优先。更多菜单也提供“上移、下移、移到最前、移到最后”。

顺序自动保存；新增待办放在最后。已完成事项默认折叠，删除后短时间内可撤销。

三条小窗

点顶部“小窗”，只显示前三条未完成待办，其余内容收起。完成一条，下一条补上。

按住顶部空白处或待办文字可移动整个窗口；拖动点阵手柄调整事项顺序。右上角斜箭头或双击空白处可展开。两种窗口位置分别记住。

时间与提醒

点“时间与提醒”，勾选设置时间，选择日期并输入 24 小时制时间。提前分钟数填 0 表示准时提醒。

  • 弹出小窗，轻闪几下：最小化或托盘状态时弹回，对应事项柔和闪烁三次。
  • 只轻闪，保持最小化：不自动弹回，手动打开时再提示。
  • 不提醒：只保留时间记录。

没有声音。程序需保持运行；关机、休眠或完全退出期间不能实时提醒，重新运行或唤醒后补提醒一次。提醒会临时置顶约 4 秒，再恢复你的置顶设置。

数据与迁移

待办、排序、草稿与设置保存在程序旁的 data 文件夹，todos.json 为当前数据，todos.json.bak 为备份。

重复安装保留已有安装数据。首次安装会尝试从本机桌面旧快捷方式对应的版本迁移；旧数据文件不会删除。迁移前请完全退出旧版。

备份或移动程序时，请一并保留 data 文件夹。分发安装包不包含你的个人待办。

常见问题

点 × 后为什么还在提醒？

× 只是收至托盘。需要完全退出时，在托盘右键菜单或设置中选择“退出轻待办”。

可以开机自动打开吗？

可以，在设置中开启“开机自动打开”。默认关闭，也可以按需开启置顶。

网页里可以直接管理真实待办吗？

这里是项目介绍、界面示意与下载网站，真实待办由 Windows 桌面程序在本机保存。

遇到问题如何反馈？

请到 GitHub Issues 描述问题和重现步骤；截图前请遮挡私人待办。
