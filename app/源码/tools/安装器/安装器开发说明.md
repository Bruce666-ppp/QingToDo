# 一键安装器

安装器为普通用户权限的 Windows 程序，将当前应用、图标、说明和源码嵌入一个 EXE，运行时无需联网。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\QingTodo`，创建桌面入口并打开应用。

执行本目录的 `BuildInstaller.ps1 -Check` 可重新生成安装器并运行 16 项安装逻辑检查。可通过 `-AppDirectory` 指定已有应用目录，`-OutputPath` 指定安装器输出位置，`-WorkDirectory` 指定构建及检查用的临时目录。应用本身先由源码根目录中的 `Build.ps1` 编译。

运行生成的 EXE 并传入 `--verify-package "某个检查目录"`，可只解包并核对内置内容，不安装、不创建桌面或启动项、不启动应用。

安装数据策略：已有安装数据优先；首次安装尝试从桌面旧入口或安装器旁的便携版迁移。迁移前验证数据，保持旧文件不变；若旧版本仍在运行，则在写入前停止安装并提示完全退出后重试。重复安装不会覆盖 `data`。更新程序文件失败时恢复本次替换的旧文件；恢复失败则保留暂存备份。

检查覆盖首次安装、内置文件完整性、旧版迁移、顺序与提醒设置保留、重复安装、旧文件损坏及备份读取、运行状态检查、写入失败恢复、路径越界、个人数据混入检测、缺失文件、快捷方式目标及暂存清理。检查在指定的隔离目录内执行，不实际安装到用户目录，不修改真实桌面、开机启动项或当前待办。
